# Contributing

This repository is for Secure Pipes bug reports, feature requests, and documentation.

- Search existing issues before opening a new one.
- Use the [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) or [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) template. For bugs, include your app/macOS versions, reproduction steps, and relevant redacted logs or screenshots.
- Documentation improvements are welcome. Write in English and open a focused pull request against `main`.

Never post passwords, private keys, license keys, sharing QR codes, share passwords, or unredacted backups. Remove sensitive details from logs and screenshots.

For private support or security reports, contact [support@secure-pipes.app](mailto:support@secure-pipes.app).
